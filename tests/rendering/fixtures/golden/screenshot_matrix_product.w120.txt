Matrix multiplication

Let

      ⎡ 1  2  3 ⎤         ⎡ −1  0 ⎤
  A = ⎢ 0  1  4 ⎥,    B = ⎢  3  2 ⎥
      ⎣ 5  6  0 ⎦         ⎣  0  1 ⎦

Since A is (3 × 3) and B is (3 × 2), the product C = A × B is (3 × 2). Each entry is a dot product:

         n
  Cᵢⱼ =  Σ  AᵢₖBₖⱼ
        k=1

╭───────┬──────────────────────────┬───────╮
│ Entry │ Computation              │ Value │
├───────┼──────────────────────────┼───────┤
│ C₁₁   │ 1 · (−1) + 2 · 3 + 3 · 0 │ 5     │
│ C₁₂   │ 1 · 0 + 2 · 2 + 3 · 1    │ 7     │
│ C₂₁   │ 0 · (−1) + 1 · 3 + 4 · 0 │ 3     │
╰───────┴──────────────────────────┴───────╯

So

      ⎡  5   7 ⎤
  C = ⎢  3   6 ⎥
      ⎣ 13  12 ⎦

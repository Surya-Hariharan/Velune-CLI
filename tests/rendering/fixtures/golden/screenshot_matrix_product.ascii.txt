Matrix multiplication

Let

      [ 1  2  3 ]         [ -1  0 ]
  A = [ 0  1  4 ],    B = [  3  2 ]
      [ 5  6  0 ]         [  0  1 ]

Since A is (3 x 3) and B is (3 x 2), the product C = A x B is (3 x 2). Each
entry is a dot product:

            n
  C_(ij) = sum A_(ik)B_(kj)
           k=1

+-------------------------------------------+
| Entry  | Computation              | Value |
|--------+--------------------------+-------|
| C_(11) | 1 * (-1) + 2 * 3 + 3 * 0 | 5     |
| C_(12) | 1 * 0 + 2 * 2 + 3 * 1    | 7     |
| C_(21) | 0 * (-1) + 1 * 3 + 4 * 0 | 3     |
+-------------------------------------------+

So

      [  5   7 ]
  C = [  3   6 ]
      [ 13  12 ]
